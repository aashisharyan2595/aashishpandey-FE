      How to send files directly between two devices

      1. 1

        Open a room with a code

        Click Get a code. You get an eight-character code, a link and a QR code. The code keeps the room open to new devices for 15 minutes, and you can extend it or close it any time.

      2. 2

        Everyone else joins

        Everyone else types the code, opens the link, or scans the QR code with a phone camera. Up to 8 devices can join, and each connects directly.

      3. 3

        Drop your files

        Drop files on any device, or send a short message or link to the room. Everyone downloads from whoever already has the pieces, then saves the file.

      Most ways of sending a file to someone upload it to a company’s server first, and the other person downloads it from there. This tool skips the server. The two browsers find each other once, then the files go straight from one device to the other, the way a video call connects two people. Nothing is kept anywhere, so there is nothing to delete afterwards.

      What it does

      • Shares any number of files of any type with the whole room, with progress, speed and time left.
      • Works both ways: once in the room, anyone can share.
      • Sends short messages and links too, handy for getting a link from your laptop onto your phone.
      • Gets faster with more people: a file is cut into pieces and devices that already hold a piece pass it on, so the sender uploads each piece about once and everyone else trades the rest between themselves.
      • Joins with an eight-character code, a link or a QR code (open for 15 minutes), or by copy and paste with no server at all.
      • Checks every piece against a fingerprint, shows whether the connection runs over your local network or the internet, and gives each pair a safety number to compare.

      Limits, honestly

      • Pages must stay open while files move. On a phone, keep the screen on. If the person who opened the room leaves, the others can keep trading what they have, but nobody new can join.
      • A few networks block even relayed connections, such as some strict corporate firewalls and VPNs. Switching the VPN off, the same Wi-Fi or a phone hotspot nearly always works.
      • Folders cannot be sent as they are. Zip them first.
      • A room holds up to 9 devices. Speed depends on the connections involved, and the sender’s upload is shared with everyone until the others have pieces to trade. On the same Wi-Fi it is usually much faster than uploading and downloading.

      What the server sees

      Here is everything that leaves your device when you use this tool, and who gets it. With copy and paste pairing, the third row does not apply either: nothing reaches my server.

      Your files and messages
      Never. They travel device to device, encrypted.
      The pairing code
      Never. Your browser turns it into a key and a room number, and only the room number is sent.
      Connection details (the network addresses the devices use to find each other)
      Encrypted with the key from the code, so the server cannot read them. Kept only while the code is open (15 minutes unless the host extends it) and deleted when the host closes the code.
      Your IP address
      Seen by the host (Vercel) as with any web page. My server counts how many codes an address makes in an hour, to stop abuse, and forgets it after the hour.
      Address lookup servers (STUN, run by Google and Cloudflare)
      Your browser asks them for its public address so the other device can reach it. They see your IP address, nothing else.
      A relay server (TURN), only if a direct path is blocked
      Forwards your already-encrypted traffic between the devices. It sees that the two IP addresses are talking and how much, never the files, names or messages.

      The full details are in the privacy policy.

      P2P File Sharing: questions and answers

      Are my files uploaded to a server?

      No. Files and messages go straight from one browser to the other over an encrypted WebRTC connection. They are never uploaded, and nothing is stored anywhere except on the device that receives them.

      How many people can download at once, and is it faster with more?

      Up to 9 devices share a room: you and 8 others. Each file is cut into pieces. Everyone asks for the pieces they lack from whichever device has them, then passes them on. So the sender uploads each piece about once, and a larger group finishes sooner than the sender could manage alone, instead of slower. The gain is largest when the sender’s connection is the bottleneck.

      What does the server see, then?

      Only the joining. To connect by code, each device leaves one short message for the host, with the details needed to find each other on the internet. It is encrypted on your device with a key made from the code and kept only while the code is open, 15 minutes unless the host extends it. The devices then introduce themselves to each other directly. The server never gets the code, the key, your file names or your files. Copy and paste pairing skips the server completely.

      Is it encrypted?

      Yes. WebRTC always encrypts every connection (DTLS), so nobody between two devices can read the files, and each piece is checked against a fingerprint the sender published. Each pair also shows a six-digit safety number. If the numbers match, you are connected to each other and not to someone in the middle.

      Is there a file size limit?

      There is no set limit. Chrome, Edge and Firefox write large incoming files to browser storage, so files of several gigabytes work if the device has the space. Other browsers keep the file in memory, which usually tops out around 1 to 2 GB on a computer and less on a phone.

      Why won’t my devices connect?

      Some networks block direct connections between devices: many office, school and hotel networks, some mobile data networks and some VPNs. When that happens the tool falls back to an encrypted relay that only forwards data it cannot read. If a connection still fails, switch off the VPN, put both devices on the same Wi-Fi, or connect one device to the other’s phone hotspot.

      Do all devices need to stay on the page?

      Yes. The files move while the pages are open, like a phone call. On a phone, keep the screen on and the browser in front until the transfer finishes. The page asks the phone to keep the screen awake while files are moving.

      Does it work between iPhone, Android, Windows and Mac?

      Yes. It works in current versions of Chrome, Edge, Firefox and Safari, on phones, tablets and computers, in any combination.

      How is this different from WeTransfer or Google Drive?

      Those upload your files to their servers and keep them for days, so the other person can download them later. Here nothing is stored, so there is nothing to leak or delete, and there is no size cap from a plan. The trade-off is that both people must be online at the same time.
