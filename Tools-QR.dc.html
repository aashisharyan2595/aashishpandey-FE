Make a QR code for a link, some text, a Wi-Fi network, an email or a phone number, then download it as PNG or SVG. The code is generated in your browser, it has no expiry date, and nothing you type is stored or tracked.

What it does

  • Links, plain text, Wi-Fi networks, email and phone numbers.
  • Your own colours, with a warning when the contrast is too low to scan.
  • Square or rounded modules, four error correction levels and an adjustable quiet zone.
  • PNG at 512, 1024 or 2048 pixels, or SVG for print.
  • A readout of exactly what the code contains, so you can check it before you use it.

Static and dynamic QR codes

A static code holds the destination itself. A dynamic code holds a short address on the vendor’s server, which then forwards the scan. Dynamic codes are what let a vendor count scans and change the destination, and they are also why a printed code can die when a free trial ends. Everything made here is static, so it keeps working and is yours. Already have a printed code and want to know which kind it is? Use the QR code checker.

Questions

Do these QR codes expire?

No. They are static codes: the link or text is written into the pattern itself, so there is no server between the scan and the destination. A code you print today scans as long as the destination exists.

Why do some QR code generators stop working after a few days?

Those are dynamic codes. They point at the vendor’s own redirect address, and when a trial or subscription ends the vendor switches the redirect off. This tool never does that. The trade-off is that a static code cannot be edited after printing and cannot count scans.

Is what I type sent anywhere?

No. The code is drawn in your browser. The text, link or Wi-Fi password you enter is not sent to a server. The page itself loads the site’s normal analytics, which record a visit but not your input.

Which error correction level should I pick?

Medium suits most screens and print. Choose Quartile or High if the code will be scuffed, curved or printed small, since more of it can be damaged and still scan. Higher levels make the pattern denser, so keep the level lower for long links.

PNG or SVG?

Use SVG for print and signage, because it stays sharp at any size. Use PNG for slides, documents and social posts. Whatever you choose, scan the finished code with a phone before printing a batch, and keep it at least 2 cm wide.

Is it safe to put my Wi-Fi password in a QR code?

Anyone who scans the code gets the password, so treat it like writing the password on the wall. It is fine for a guest network in a place you control, and a poor idea for your main network on a public poster.

Can I use the codes commercially?

Yes, there is no fee and no watermark. Denso Wave, which invented the format, has said it will not enforce its patent rights on standard QR codes. “QR Code” is a registered trademark of Denso Wave.
