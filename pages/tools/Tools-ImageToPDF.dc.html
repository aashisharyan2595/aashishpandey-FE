    How to turn images into a PDF

    1. 1

      Add your pictures

      Drop them on the box, paste them, or click to choose. You can add more at any time.

    2. 2

      Set the order and page

      Use the arrows to reorder and the rotate button for sideways pictures. Choose A4 or fit-to-picture pages.

    3. 3

      Create and download

      Press Create PDF, check the first page, and download the file.

    A PDF is easier to send than a folder of photos. Portals ask for one file, offices want a single attachment, and a PDF keeps the pages in order on every device. This tool builds that file in your browser from the pictures you pick.

    Each picture becomes one page. Pages can match the picture exactly, or sit on a clean A4 sheet with a margin, which looks better for scans of documents. If the file comes out too big, switch the quality to Balanced or Small. If it still has to be under a set size, run it through the PDF compressor afterwards.

    What about HEIC photos from an iPhone?

    Most browsers cannot read HEIC files. Safari can. If a file is skipped, change the iPhone camera format to Most Compatible, or export the photo as JPG first.

    What it does

    • Combine any number of JPG, PNG and WebP pictures into one PDF, in the order you set
    • Move pictures up or down, rotate them, remove them, or sort by file name
    • Pages that fit each picture, or A4 portrait, sideways or automatic, with a margin you choose
    • Three quality levels, so a phone photo does not turn into a 20 MB file
    • Phone photos are turned the right way up using their camera orientation
    • Runs on your device, with no daily limit and no watermark on the PDF

    Image to PDF Converter: questions and answers

    How do I convert several images into one PDF?

    Add all the pictures, set their order with the arrows, then press Create PDF. Each picture becomes one page in the order shown. The file downloads straight to your device.

    Can I make the PDF smaller?

    Yes. Set the quality to Balanced or Small before you create it. For an exact limit such as 200 KB, make the PDF here and then run it through the PDF compressor with your target size.

    Will the pictures be uploaded?

    No. The page reads the pictures in your browser and builds the PDF there. Nothing is sent to a server and nothing is stored.

    Why does my picture appear sideways?

    Use the rotate button on that picture. Photos taken on a phone are usually turned correctly on their own, but scans and screenshots can come in sideways.

    Which page size should I choose?

    Pick Fit to picture when every picture should fill its page. Pick A4 for documents and forms, where you want a standard page with a margin. Automatic A4 turns the page sideways for wide pictures and keeps it upright for tall ones.

    Does it work with PNG with transparent backgrounds?

    Yes. Transparent areas become white, because the pages are saved as pictures without transparency.
