    Structured data is a block of code on a page, usually JSON-LD, that describes the page to search engines in a form they can read exactly: the product and its price, the article and its author, the business and its opening hours. Google recommends JSON-LD over other formats. This generator writes valid markup for the most useful types and checks it for missing fields, so you do not need to learn the vocabulary or hand-edit commas and brackets.
    What it does
    • Writes valid JSON-LD for FAQ pages, how-to guides, articles, products, local businesses, organizations, events and breadcrumb trails.
    • Checks each type for the fields Google asks for, and says what is missing in plain words.
    • Gives you the markup as a script tag ready to paste, or as plain JSON.
    • Leaves out empty fields, so you never publish blank values.
    • Fills in an example for each type, so you can see what a complete one looks like.
    • Never adds ratings or reviews. Those must come from real reviews shown on the page.
    Limits, honestly
    • Valid markup is not a promise of a rich result. Google chooses what to show, and it has cut back some types: FAQ rich results now appear only for some government and health sites, and how-to rich results are no longer shown.
    • The markup must match what visitors can see on the page. Marking up content that is hidden or not there can lead to a manual action.
    • It covers eight common types, not the whole Schema.org vocabulary. For anything else, write the code by hand or extend the output.
    • It checks structure and the fields Google lists. It does not fetch your page, so run the live page through the Rich Results Test.
    • Event times have no time zone unless you add one to the output.
    
    
    JSON-LD Schema Generator: questions and answers
    
      
    What is JSON-LD?
    JSON-LD is a way of writing structured data as a small block of JSON inside a script tag on a page. Search engines read it to learn exactly what the page is about: its product, article, business, event and more. Google recommends it over microdata and RDFa.
    Where do I put JSON-LD on my page?
    Paste the script tag into the head or the body of the page it describes. Both work. On WordPress, Shopify and other platforms you can add it through a theme file, a custom HTML block or an SEO plugin.
    Will schema markup improve my rankings?
    Not directly. Structured data is not a ranking factor on its own. It can make a page eligible for richer results, such as price, availability or event details, which can help clicks, and it helps search engines understand the page.
    How do I test my structured data?
    Run the live page through Google’s Rich Results Test, which shows which rich results it can use and any errors, and the Schema.org validator, which checks the markup against the vocabulary. Then watch the enhancement reports in Search Console.
    Why does Google not show my FAQ or how-to rich result?
    Google limited FAQ rich results to well-known government and health sites in 2023, and stopped showing how-to rich results. The markup is still valid and still describes the page, but you should not expect those boxes in search.
    Can I add review stars with this tool?
    No, on purpose. Review and rating markup is only allowed for genuine reviews that visitors can read on the page. Invented or self-written ratings can cause Google to remove your rich results.
    Which schema type should I use for my page?
    Use the type that matches the main thing on the page: Product for a product page, Article for a post, LocalBusiness for a shop or office, Organization for the home page, Event for a dated event and BreadcrumbList for the trail above a page. A page can carry more than one.
    Is my data sent anywhere?
    No. The markup is built in your browser and nothing you type is uploaded.
    Can it make Recipe or Person schema?
    Yes. Recipe gives you ingredients, steps, prep and cook times, yield and calories, and checks the name and photo Google needs for recipe rich results. Person is for an about page: name, job, employer, photo and the profiles that belong to the same person, linked with sameAs.
