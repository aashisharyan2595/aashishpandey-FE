    How to create an llms.txt file
    
      
    1. 1
      Describe the site
      Give it a name, a one-line summary and, if it helps, a short note on who it is for and what an assistant should know.
    2. 2
      Add your best pages
      Group links into sections such as Docs and Product, with a few words on each page. Paste a list of addresses to start faster.
    3. 3
      Download and upload
      Check the notes, download llms.txt and put it in the root of your site, at /llms.txt.
    
    
    llms.txt is a plain Markdown file at the root of a site that gives language models a short, curated map of it: what the site is, and which pages matter. It was proposed as a way to help AI assistants find the right pages without wading through navigation, scripts and ads. This generator writes the file in the proposed layout and checks it for the mistakes that make it less useful.
    What it does
    • Writes the file in the llmstxt.org layout: a title, a one-line quote, optional notes, then sections of links.
    • Lets you group pages into sections, with an Optional section for pages an assistant can skip when short of space.
    • Creates links from a pasted list of addresses, with titles worked out from each address.
    • Checks for a missing name or summary, links that are not full addresses, links with no description, repeats and files that run long.
    • Shows the file with colour as you edit, and copies or downloads it.
    Limits, honestly
    • llms.txt is a proposal, not a standard. Some AI products read it and many do not, and no one promises it improves how you appear in AI answers.
    • It does not replace robots.txt, a sitemap or good page content. It sits beside them.
    • It only describes the pages you list. It does not crawl your site, so it cannot find pages for you.
    • Keep it short and current. A file full of old or broken links is worse than none.
    • For a longer version that holds the full text of your documentation, publish a separate llms-full.txt. This tool writes the short file.
    
    
    llms.txt Generator: questions and answers
    
      
    What is llms.txt?
    It is a Markdown file placed at the root of a website, at /llms.txt, that gives language models a short guide to the site: a summary and a list of the most useful pages with a few words on each. The format was proposed at llmstxt.org.
    Do ChatGPT, Claude and Perplexity read llms.txt?
    Support is uneven and changes over time. Some tools and developer integrations read it, and many search crawlers do not. Treat it as a low-cost, helpful summary and not as a ranking switch.
    What goes in an llms.txt file?
    A title with the site name, a one-line summary in a quote, optional notes, and then sections of links written as a dash, the title in square brackets, the address in brackets and a short description. A section named Optional marks lower-priority pages.
    Where do I put llms.txt?
    In the root of your domain so it opens at https://yourdomain.com/llms.txt, the same place as robots.txt. On many hosts that means the public or static folder of your project.
    What is the difference between llms.txt and robots.txt?
    robots.txt tells crawlers what they may fetch. llms.txt describes what is worth reading. One restricts and the other guides, so a site can have both.
    How long should llms.txt be?
    Short enough for a model to read in full: a handful of sections and a few dozen links at most. Put the main pages first and move extras to the Optional section.
    Is my information sent anywhere?
    No. The file is built in your browser and nothing you type is uploaded.
    Can I make an llms.txt from my sitemap?
    Yes. Open your sitemap.xml in the browser, copy all of it and paste it into “Add pages from a list”. The page addresses are taken from its loc tags, duplicates and image links are dropped, and up to 200 pages are added. Then group them into sections and keep only the pages an assistant really needs.
