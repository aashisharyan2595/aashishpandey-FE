Free online tools: questions and answers

Are the tools free?

Yes. All of them are free and none needs an account.

Is there a free resume maker with no sign-up?

Yes. The Resume Maker is free, needs no account and runs in your browser, so your details are not uploaded. It has 30 ATS-friendly templates and eight job-based examples, and it exports to PDF and Word.

Do the QR codes expire?

No. The QR code generator makes static codes, so the link is stored in the code itself and keeps working as long as the destination does. Download them as PNG or SVG.

Can I print the QR codes on packaging or posters?

Yes. The QR code generator makes static codes with no expiry, no tracking and no watermark, so they are safe to print.

How can I tell if a QR code is dynamic?

Drop it into the QR code checker. It reads the code and shows whether it points to a redirect that the provider can switch off.

How do I remove location data from a photo?

Open the photo metadata remover and add the photo. It shows the GPS location and camera details stored in the file, then removes them.

How do I check a file’s SHA-256 hash?

Open the file hash checker, add the file and paste the value the publisher lists. It calculates MD5, SHA-1, SHA-256 and SHA-512 and shows whether they match.

Do you store my data?

The notepad, image resizer, lorem generator, checklist, password generator and resume maker keep everything on your device. The URL shortener stores the link you give it, its short code and a click count until the link expires.

Do I need to install anything?

No. Every tool runs in your web browser on desktop or mobile.

Do the tools work on a phone?

Yes. Each tool works on phones and tablets as well as on a computer.
