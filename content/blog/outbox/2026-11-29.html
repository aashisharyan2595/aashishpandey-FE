Quick answer. Qwen4-Max is Alibaba's cheaper flagship model: $1.50 in and $4.50 out per million tokens, with a 1M context window. Alibaba's charts look strong, but one independent index ranks it 12th, well behind Claude Opus 5.5.

What is Qwen4-Max?

Qwen4-Max is the new top model from Alibaba. It has 2.4 trillion parameters in total, but it's a mixture-of-experts design, so only 71 billion are active for each token it processes. It reads images natively and has a one-million-token context window.

Alibaba unveiled it on a Sunday and opened it up the next day, after a limited preview that began on 11 November. It's the first model in the Qwen4 family, and it follows Qwen3.8-Max, which came out in August.

What's new compared with the last one?

The pitch is more work per dollar. Alibaba says Qwen4-Max beats Qwen3.8-Max overall on its own Work360 benchmark while using 35% fewer tokens and cutting the average cost per task by around 60%. The press coverage quotes slightly different figures for that saving: Digital Trends reports $4.43 down to $1.67 per task, and TechNode reports about 58% in yuan. All of it comes from Alibaba's own benchmark, so read it as a vendor claim.

Alibaba also says it filtered the training data for cyber risk, keeping defensive material for finding and fixing vulnerabilities and removing offensive attack content. Its coding training included security checks as well as functionality tests.

How does it hold up in practice?

Depends on whose numbers you trust. On Alibaba's launch chart, the model comes first on four of 14 rows. One is DeepSWE, where the spread across all six models is only 1.6 points, so LLM Stats calls it a tie. Alibaba adds that it placed 6th on Code Arena, which scores real-world coding.

The independent picture is less flattering. The Super Intel newsletter reports that Artificial Analysis puts Qwen4-Max at 43 on its Intelligence Index, in 12th place. Kimi K3.1 Pro sits 3 points higher at 46, Claude Opus 5.5 is on 59, and the leader, Claude Fable 5.2, is on 65. The same report says Alibaba's own numbers aren't wrong where both measured the same test. The gap comes from which tests and which rivals you pick. Against its predecessor, the progress is real: 9 points higher and about a third of the cost per task ($3.27 against $10.02).

One more catch from LLM Stats: Alibaba's launch scores were run at the highest effort setting, xhigh, while the API runs on high by default. Treat the launch numbers as an upper bound unless you set xhigh yourself.

Pros

  • List price is $1.50 per million input tokens and $4.50 per million output, against $4 and $20 for Claude Opus 5.5. LLM Stats works out a job with 10 million tokens in and 2 million out at $24 on Qwen4-Max against $80 on Opus 5.5.
  • Prices are the same across the full one-million-token context, with no long-context surcharge.
  • It's a real step up from Qwen3.8-Max, better on every shared row of Alibaba's table, and the independent index agrees it improved.
  • Its self-reported wins are in long-horizon agent tests and a biology test, so it does best on the kind of long agent work that burns the most tokens.

Cons

  • Independent tests put it behind the leaders. Twelfth place and 16 points behind Opus 5.5 on one broad index is a long way down.
  • Terminal-first coding is a weak spot. On Alibaba's own table it scores 31.5 on ProgramBench against 65.0 for Opus 5.5, and 48.5 on Terminal-Bench 4.0 against 67.2 for Kimi K3.1.
  • The weights are closed. Unlike Qwen3.8-Max, there's no open-weights release for the flagship. Alibaba only promises open-source releases of smaller Qwen4 models, and gives no date.
  • The safety claims are Alibaba's own. Digital Trends notes that no external red team has tested the model yet, and LLM Stats says no third-party system card is published.

Who it's for, and who should skip it

If you're running long research, legal, health or business-analysis agents and the bill is the problem, Qwen4-Max is worth a test on your own tasks. LLM Stats says moving from Qwen3.8-Max is a yes, and testing it against Opus 5.5 or GPT-6 Astra for long-horizon agent work.

Skip it if you need a terminal-first coding agent, chart-heavy or video-heavy input at the top end, open weights you can host yourself, or a batch discount. It doesn't offer batch pricing.

If you work in a regulated business or handle sensitive data, check where your data goes before you send it anywhere. The model is offered through Alibaba's QwenCloud and apps, and I haven't seen an independent security review of it.

Price and availability

The model is on QwenCloud through a Token Plan and the API, per Alibaba, and in Qwen Studio, QwenWork and Qoder, according to TechNode. LLM Stats lists Singapore list prices of $1.50 in and $4.50 out, and slightly lower rates in Beijing and the global regions. It also lists OpenRouter as a way in. Singapore pay-as-you-go includes 1 million free tokens for 90 days.

My take

I'd read Qwen4-Max as a good price cut from a lab that's still catching up. The independent ranking shows a clear upgrade on Qwen3.8-Max and a gap to the top Claude models. For a small team with a heavy, repeatable agent job, I'd run a week of real tasks at the xhigh setting, count the cost per finished task, and compare it to what you pay now. For coding work I'd stay where I am.

Alibaba's own Work360 benchmark only reports Qwen models, so the cost savings are the claim I'd trust least until someone outside checks them.

No left, centre or right news outlets split on this story, so I haven't tried to balance one against the other. The pages I could read in full were Alibaba's announcement, a Reuters report carried by The Standard in Hong Kong, and trade and independent analysis sites.

Frequently asked questions

What is Qwen4-Max?

Qwen4-Max is Alibaba's flagship AI model, released on 16 November 2026. It's a mixture-of-experts model with 2.4 trillion total parameters and 71 billion active per token, native image input and a one-million-token context window. It's available through QwenCloud's API and Token Plan and in Alibaba's Qwen apps, but the weights aren't public.

How much does Qwen4-Max cost?

The Singapore list price is $1.50 per million input tokens and $4.50 per million output, according to LLM Stats, and it stays flat across the whole context window. Claude Opus 5.5 lists at $4 in and $20 out. Beijing and global regions are slightly cheaper, and there's no batch discount.

Is Qwen4-Max better than Claude Opus 5.5?

Not overall on the independent evidence. Artificial Analysis, as reported by Super Intel, scores Qwen4-Max 43 against 59 for Opus 5.5. Alibaba's own table has it ahead on some agent tests and behind on terminal coding and ProgramBench. Test it on your own work before switching.

Is Qwen4-Max open source?

No. Unlike Qwen3.8-Max, the flagship has no open weights. Alibaba says smaller Qwen4 models will be released as open source soon, but hasn't given a date, so you can't host Qwen4-Max yourself and have to use Alibaba's cloud or an API partner.

Should I switch from Qwen3.8-Max?

LLM Stats says yes: Qwen4-Max is better on every shared benchmark row, uses fewer tokens and lists about 25% cheaper in Singapore. The exception is if you need open weights you can self-host, which only Qwen3.8-Max offers. Set the effort level to xhigh if you want results close to the launch scores.
